# JSON Reader

Lightweight offline JSON / JSONL table reader.

- Single HTML file
- Open one or more local JSON or JSONL files
- Search, filter, sort, resize columns, wrap text
- Freeze first row, first column, or last column
- Double-click cells to edit and save changes locally, preserving the original JSON or JSONL format

Open `index.html` in Chrome or Edge. Files stay on your computer.
